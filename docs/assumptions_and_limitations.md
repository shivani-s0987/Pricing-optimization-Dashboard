# Assumptions and Limitations

- All data are synthetic. Names, regions, prices, costs, demand, trends and findings are illustrative.
- One transaction line per generated order means distinct order count equals line count; real order-level analysis usually has multiple lines per order.
- Gross profit is not net profit and excludes returns, taxes, shipping, payment processing, marketing and overhead.
- Discounts and observed performance are associated in the dataset; causation is not established. Use controlled experiments or credible causal methods to estimate elasticity.
- Current product master prices/costs are not historical values. No verified competitor benchmark is supplied.
- The Excel workbook includes formula-driven KPI cells and analysis tables/charts. Full native PivotTables and slicers are not generated by this automated build; users can add them in Excel using the supplied structured tables.
- Power BI Desktop is not available in this Linux environment. No PBIX is included; DAX, schema, model diagram, theme, and five-page build specification are provided.
- PostgreSQL server/client is not available in this environment; SQL is provided for PostgreSQL and Python-based dataset/report/tests are executed locally. Database integration remains untested here.
- Reporting scripts generate static CSV/Markdown/PDF outputs. Scheduled execution and Power BI Service refresh/email subscriptions require user-owned infrastructure and are not configured.
